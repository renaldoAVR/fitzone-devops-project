# FitZone Fitness Website — Week 3 DevOps Group Activity

A responsive five-page static website built with HTML, CSS, and JavaScript for a group collaboration assignment.

## Pages
- `index.html` — Home
- `about.html` — About
- `services.html` — Services
- `contact.html` — Contact form demo
- `login.html` — Login form demo

## Other files
- `style.css` — Shared responsive design
- `script.js` — Mobile navigation, footer year, and demo form feedback

## Run locally
Open `index.html` in a browser, or use VS Code with the Live Server extension.

## Important limitations
This is a front-end student demo. The contact form does not send or store messages. The login form does not authenticate users. Do not enter real passwords or sensitive information.

## Suggested team branch names
- `home-page`
- `about-page`
- `services-page`
- `contact-page`
- `login-page`

## Suggested GitHub Pages deployment
1. Push the final merged project to the repository's `main` branch.
2. On GitHub, open **Settings → Pages**.
3. Under the build/deployment source, choose **Deploy from a branch**.
4. Choose branch `main` and folder `/(root)`, then save.
5. Wait for the deployment to finish and open the URL displayed in Settings → Pages.

## Suggested workflow
Create one branch per page, commit work, push the branch, open a Pull Request, review it, and merge it into `main`. Test the full site after each merge.
