# FitZone Fitness Website — Week 3 DevOps Group Activity

A responsive five-page static fitness website built using HTML, CSS, and JavaScript as part of a collaborative DevOps group assignment. The project demonstrates Git branching, team collaboration, pull requests, code reviews, and GitHub Pages deployment.

## Pages

- `index.html` — Home
- `about.html` — About
- `services.html` — Services
- `contact.html` — Contact form demo
- `login.html` — Login form demo

## Run locally

1. Clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension, or open it directly in a web browser.

## Important limitations

This is a front-end student demonstration project.

- The contact form does not send or store messages.
- The login form does not authenticate users.
- Do not enter real passwords or sensitive information.

## Git Collaboration Workflow

1. Clone the repository.
2. Create a separate branch for your assigned page.
3. Make changes to the relevant files.
4. Stage and commit your changes with a descriptive commit message.
5. Push your branch to GitHub.
6. Open a Pull Request targeting `main`.
7. Ask another team member to review the changes.
8. Merge the approved Pull Request into `main`.
9. Test the complete website after integration.

**Important:** Follow the repository's branch protection rules when merging changes into `main`.

## GitHub Pages deployment

After the team has integrated and tested the website:

1. Push the final approved changes to `main`.
2. Open the repository's **Settings → Pages**.
3. Under the build and deployment settings, select **Deploy from a branch**.
4. Choose `main` as the branch and `/(root)` as the folder.
5. Save the settings and wait for deployment to complete.
6. Open the published website URL shown in the Pages settings.

The goal of this project is to practice collaborative web development and essential DevOps workflows, including version control, branching, pull requests, code reviews, integration, and deployment.
